1. 用户模型 (users 表)

源文件: /Users/bytedance/self/llm-center/internal/model/user.go | 模型名: User

字段名 (Go) 数据库类型 描述 备注
ID BIGINT UNSIGNED 用户唯一标识符 主键
Username VARCHAR(50) 用户名 唯一索引
Password VARCHAR(100) 用户密码 (通常存储哈希值)
Email VARCHAR(100) 用户邮箱地址 唯一索引

Company VARCHAR(255) 用户所在公司
Location VARCHAR(255) 用户所在地理位置
Bio TEXT 用户个人简介
DeletedAt DATETIME NULL 软删除时间 由 GORM 自动管理 (如果启用了软删除)

2. Agent 模型 (agents 表)

源文件: /Users/bytedance/self/llm-center/internal/model/agent.go | 模型名: Agent

字段名 (Go) 数据库类型 描述 备注
ID BIGINT UNSIGNED Agent 唯一标识符 主键
Name VARCHAR(100) Agent 名称 非空
Description TEXT Agent 详细描述
SystemPrompt TEXT Agent 的系统提示词
ModelName VARCHAR(100) Agent 默认使用的 AI 模型名称
CreatorID BIGINT UNSIGNED 创建该 Agent 的用户 ID 索引, 外键关联到 users.id
Status INT Agent 状态 (例如: 1=启用, 0=禁用) 默认为 1
IsPublic BOOLEAN Agent 是否公开 默认为 false
Temperature DOUBLE 模型生成的温度参数
TopP DOUBLE 模型生成的 Top-P 采样参数
TopK DOUBLE 模型生成的 Top-K 采样参数
Avatar TEXT Agent 的头像链接或 Base64 数据
RagEmbeddingID BIGINT UNSIGNED NULL 关联的 RAG 嵌入记录的 ID (可选) 索引, 外键关联到 rag_embeddings.id
CreatedAt DATETIME 创建时间 由 GORM 自动管理
UpdatedAt DATETIME 最后更新时间 由 GORM 自动管理
DeletedAt DATETIME NULL 软删除时间 由 GORM 自动管理
